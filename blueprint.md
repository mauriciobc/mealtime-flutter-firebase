# MealTime App Blueprint

## Overview

MealTime is a Flutter application designed to help users track their daily caloric intake. It features user authentication, a meal tracker, and a personalized dashboard.

## Features

*   **User Authentication:** Users can sign up and log in using their email and password.
*   **Meal Tracking:** Users can add meals with their corresponding calorie counts.
*   **Dashboard:** A personalized dashboard displays a list of meals consumed by the user.
*   **Theme Toggle:** Users can switch between light and dark themes.

## Style and Design

*   **Theme:** The app uses a Material 3 theme with a primary color of deep purple.
*   **Fonts:** The app uses Google Fonts for a modern and readable typography.
*   **Layout:** The app uses a clean and simple layout with intuitive navigation.
